# Forever Young 0.1.0 Preview

The first preview loads the original Young Link body, clothes, face, hair, and skeleton during Adult gameplay. It uses Young Link animations and replaces 352 Adult voice bank cues and 331 loose voice streams. The Adult gameplay actor still controls equipment, abilities, and story age.

Tested on NX2navi 0.10.1 with game update 1.1.1. On a disposable Adult save, Young Link rendered while running and in the real-time Sun's Song sequence. Sword and shield worked, and the Hookshot trace showed aim, launch, and return.

The Fairy Bow and other Adult equipment animations still need work. The story age transition is untested. See README.md for setup and removal.

This archive contains the builder and documentation. Run the builder against your local game installation to generate the NX2navi override.
